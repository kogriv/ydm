    completed_folders >= 100 or
    self.last_checkpoint_files >= 10000 or
    elapsed >= 300  # 5 минут
  )

Проблемы:
  
  1. Условие "completed_folders >= 100":
     - Скан 8 имеет 5746 папок BUT только 1 completed!
     - Остальные в in_progress (не считаются в condition)
     - Условие требует ЗАВЕРШЕННЫЕ папки, не в_процессе
     - Следовательно: в течение 1.5 часов только 1 папка завершена?
       Это невозможно или...
       Может быть API Яндекса возвращает папки с разной скоростью?
  
  2. Условие "files >= 10000":
     - Скан 8: 0 файлов! (хотя сканировал 5746 папок)
     - Вероятно: файлы не были добавлены в first checkpoint
     - Или: процесс убит перед тем как добавить файлы
  
  3. Временной интервал (5 мин):
     - Скан 8 работал 1.5 часа
     - 5-минутный интервал пройден много раз
     - Checkpoint ДОЛЖЕН был сработать
     - Но он не сработал!
  
  ВЫВОД: Возможно было:
    a) Exception в checkpoint() коде
    b) Процесс убит БЕЗ checkpoint (kill -9)
    c) Checkpoint выполнился но в /dev/shm, не на диск
