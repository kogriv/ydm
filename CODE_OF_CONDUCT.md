# Code of Conduct

This is a small utility project maintained largely by one person, but
everyone is welcome to open issues, submit pull requests, or ask
questions.

A few basic expectations:

- Be respectful. Disagree about code and approaches, not about people.
- No harassment, personal attacks, or discriminatory language/behavior,
  in issues, PRs, or anywhere else related to this project.
- Assume good faith — most disagreements here are about tradeoffs, not
  malice.

If someone's behavior in this project's spaces makes you uncomfortable,
please open an issue describing what happened (or, if it involves the
issue tracker itself, reach out through the repository's contact method).
Reports will be handled discreetly and taken seriously.
