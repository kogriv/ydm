Репозиторий был приватным на GitHub, зеркало — GitLab. Лицензия MIT,
`CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` на месте с января. Эта
задача отвечает на один вопрос: что произойдёт, если переключить видимость на
public.

## Коротко

**Блокер был один, и он наполовину закрыт 24.08.** В истории лежали около
206 КБ перечня личных файлов владельца — пять файлов, закоммиченных в
первоначальном коммите и убранных только из рабочего дерева. Утечки не было:
репозиторий приватный. История переписана (`git filter-repo`), тем же проходом
убрано имя третьего лица из фикстур; `.git` ужался с 4,1 МБ до 1,8 МБ.

**Но переписывания оказалось мало.** Форс-пуш переставляет ветку, а объекты
живут до сборки мусора — и оба сервера по-прежнему отдают старый коммит по
прямому SHA. На GitLab перепробованы все средства интерфейса (housekeeping,
repository cleanup, remove blobs); ссылок на старую историю не осталось, но
сам объект жив: у висячих объектов `git` держит период отсрочки, обычно две
недели.

Значит блокируется **не работа над проектом, а ровно один момент** —
переключение видимости. Проверка перед ним занимает секунды, и делать её надо
непосредственно перед публикацией. Подробности и журнал попыток — Phase 5 в
[`BACKLOG.md`](./BACKLOG.md).

**Секретов нет.** Перебраны все 385 блобов истории по шаблонам токенов —
ноль совпадений. `.env` и `*.db` не коммитились ни разу. Сетевых адресов в
коде два, оба яндексовые.

**Остальное — не блокеры:** README открывается пятнадцатью алиасами, которых
после клона не существует; `/data/ya_disk` вшит как дефолт; личные имена папок
в фикстурах и комментариях; две трети документации только по-русски.

Разбор — [`GAP.md`](./GAP.md), работа — [`BACKLOG.md`](./BACKLOG.md).

В корне лежит неотслеживаемый `GITHUB_READINESS_REPORT.md` от 30 января с
вердиктом «готов к публикации, 9/10». **Он недействителен**, и не только
из-за возраста:

- пункт «удалить служебные файлы из истории git» помечен ✅ с командой
  `git rm --cached`, которая историю не трогает;
- два пункта оставлены открытыми — проверка истории на секреты и судьба
  `poligon_endpoints.png`. Оба закрыты здесь: секретов нет, скриншот
  безвреден (список эндпоинтов API, без токена).

Судьба самого файла — развилка 4.4 в бэклоге.
