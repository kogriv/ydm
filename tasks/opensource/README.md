# Open source readiness

*Статус:* **аудит проведён, работа не начата**
*Дата:* 2026-08-24

Репозиторий приватный на GitHub, зеркало — GitLab. Лицензия MIT,
`CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` на месте с января. Эта
задача отвечает на один вопрос: что произойдёт, если переключить видимость на
public.

## Коротко

**Блокер один.** В истории лежат около 84 КБ перечня личных файлов владельца —
`junk_list.txt`, `deleted.log.old`, `junk_analysis.json`, `cleanup_paths.txt`,
закоммиченные в `4858601f`. Из рабочего дерева убраны, из истории — нет.
Утечки не было: репозиторий приватный. Переписать дёшево — 65 коммитов,
`.git` 3,7 МБ.

**Секретов нет.** Перебраны все 385 блобов истории по шаблонам токенов —
ноль совпадений. `.env` и `*.db` не коммитились ни разу. Сетевых адресов в
коде два, оба яндексовые.

**Остальное — не блокеры:** README открывается пятнадцатью алиасами, которых
после клона не существует; `/data/ya_disk` вшит как дефолт; личные имена папок
в фикстурах и комментариях; две трети документации только по-русски.

Разбор — [`GAP.md`](./GAP.md), работа — [`BACKLOG.md`](./BACKLOG.md).

## Про январский отчёт

В корне лежит неотслеживаемый `GITHUB_READINESS_REPORT.md` от 30 января с
вердиктом «готов к публикации, 9/10». **Он недействителен**, и не только
из-за возраста:

- пункт «удалить служебные файлы из истории git» помечен ✅ с командой
  `git rm --cached`, которая историю не трогает;
- два пункта оставлены открытыми — проверка истории на секреты и судьба
  `poligon_endpoints.png`. Оба закрыты здесь: секретов нет, скриншот
  безвреден (список эндпоинтов API, без токена).

Судьба самого файла — развилка 4.4 в бэклоге.
