## Вопрос 3 — `_dir_size()` на `/sdcard` (то, чего нельзя измерить здесь)

Пункт 9.3 бэклога **намеренно не тронут**. На настольной машине обход
локального зеркала стоит 0.22 с из 11.8 с профиля — то есть ничего. Но там
обычный диск, а у вас FUSE поверх общего хранилища, и цена может быть совсем
другой. Править вслепую я не стал.

Профиль снимет ответ:

```bash
python3 -m cProfile -o /tmp/orph.prof tools/ydm_menu.py \
  --local-root "$YDM_LOCAL_ROOT" orphans >/dev/null
python3 -c "
import pstats; pstats.Stats('/tmp/orph.prof').sort_stats('tottime').print_stats(12)
"
```

**Что смотреть:** строки `posix.stat`, `os.walk`, `_dir_size`, `posix.scandir`.
Если вместе они дают заметную долю — 9.3 стоит делать, и тогда уже понятно,
что именно. Если нет — закроем пункт как несуществующий, и это тоже ответ.

## Вопрос 4 — `ydm` теперь меню, а не CLI

PR #12 вернул `ydm` значение «интерактивное меню», а голый CLI переехал в
`ydm-cli`. Здесь свой `~/.bashrc` на 463 строки, и он старше этого файла.

```bash
grep -n "alias ydm=\|ydm()" ~/.bashrc | head
bash -c 'source tools/aliases.sh; type ydm; type ydm-cli; type ydm-sync-state'
```

**Что проверяем:** подключение `tools/aliases.sh` поверх вашего `~/.bashrc`
ничего не ломает и `ydm` остаётся меню. Если какая-то ваша команда пропадает
или меняет смысл — назовите её, это дефект файла, а не вашей настройки.

## Вопрос 5 — фильтр bisync по умолчанию

PR #11 изменил дефолт `--filter-path` на бидирекционный фильтр. Плановая
задача передаёт флаг явно, так что на неё это не влияет — но всё, что зовёт
инструмент напрямую, до сих пор сверяло не тот файл.

```bash
python3 tools/sync_bisync.py status --local-root "$YDM_LOCAL_ROOT" \
  --format text
```

**Ожидается:** `filter_path` заканчивается на `.bisync.filters`, и
`resync_needed: False`. До правки то же самое давало `True` неделями.

Заодно — отказ на `resync`, он должен сработать **до** rclone:

```bash
python3 tools/sync_bisync.py resync --local-root "$YDM_LOCAL_ROOT" \
  --filter-path "$YDM_LOCAL_ROOT.download.filters"
```

**Ожидается:** отказ с объяснением и подсказкой про `--force-filter`. Ничего
не запускается. Это единственная команда здесь, которая *могла* бы что-то
изменить, — она и проверяется на то, что не изменит.
