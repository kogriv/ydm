# Результаты тестирования exclude-dirs для файлов

**Дата:** 06.01.2026  
**Тестируемый файл:** `video/m.jpg` (7.8 MB)

---

## Тест 1: Добавление файла в exclude-dirs (файл уже локально)

**Действия:**
1. Файл `video/m.jpg` существует локально
2. Добавлен `video/m.jpg` в `exclude-dirs` в конфиге
3. Перезапущен yandex-disk

**Результат:**
- ❌ Файл **НЕ удалился** автоматически
- Файл остался локально, несмотря на правило исключения

**Вывод:** `exclude-dirs` не удаляет уже существующие локальные файлы.

---

## Тест 2: Удаление файла локально (файл в exclude-dirs)

**Действия:**
1. Файл удален локально вручную (`rm`)
2. Файл `video/m.jpg` в `exclude-dirs`
3. Файл существует в облаке
4. Перезапущен yandex-disk

**Результат:**
- ❌ Файл **НЕ загрузился** из облака
- Файл остался удаленным локально

**Вывод:** `exclude-dirs` предотвращает загрузку файла из облака, если его нет локально.

---

## Тест 3: Добавление файла в облако (файл в exclude-dirs)

**Действия:**
1. Файл `video/m.jpg` добавлен обратно в облако
2. Файл `video/m.jpg` в `exclude-dirs`
3. Файла нет локально
4. Ожидание синхронизации

**Результат:**
- ❌ Файл **синхронизировался** локально, несмотря на правило исключения
- Файл появился на локальном диске

**Вывод:** `exclude-dirs` **НЕ работает для файлов** - файлы синхронизируются даже если они в списке исключений.

---

## Итоговые выводы

1. **`exclude-dirs` НЕ работает для файлов:**
   - Файлы синхронизируются из облака, даже если они в `exclude-dirs`
   - Правило исключения игнорируется для файлов

2. **`exclude-dirs` работает только для папок:**
   - Папки корректно исключаются из синхронизации
   - Файлы внутри исключенных папок не синхронизируются

3. **Решение для исключения файлов:**
   - Переместить файл в исключенную подпапку через API
   - Пример: `video/test.avi` → `video/excluded_files/test.avi` (где `video/excluded_files` в `exclude-dirs`)
   - Или удалить файл в облаке через API

---

## Рекомендации для sync_manager

Утилита должна:
- Предупреждать о файлах в корне синхронизируемых папок
- Предлагать переместить файл в исключенную подпапку
- Не пытаться добавлять файлы в `exclude-dirs` (это не работает)
