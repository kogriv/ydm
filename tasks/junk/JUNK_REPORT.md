## Действия для очистки

### Шаг 1: Удаление виртуальных окружений (КРИТИЧНО)

Список всех venv папок сохранен в `cleanup_paths.txt` (42 пути).

**Способ 1: Через веб-интерфейс Яндекс.Диска**
1. Открыть https://disk.yandex.ru
2. Найти папку `pro/bquant_project/venv_bquant_dell`
3. Удалить (правая кнопка → Удалить)
4. Повторить для всех venv папок

**Способ 2: Через API (автоматизация)**
Создать скрипт для удаления через Yandex Disk REST API.

### Шаг 2: Очистка .git репозиториев

1. Проверить remote для каждого проекта:
```bash
cd /data/ya_disk/pro/vcpkg
git remote -v
```

2. Если есть remote → безопасно удалить `.git`:
```bash
rm -rf .git
```

3. Если нет remote → сначала создать:
```bash
git remote add origin <URL>
git push -u origin main
```

### Шаг 3: Очистка __pycache__ и build

Локально выполнить:
```bash
cd /data/ya_disk/pro
find . -type d -name "__pycache__" -exec rm -rf {} +
find . -type d -name "build" -exec rm -rf {} +
find . -type d -name "dist" -exec rm -rf {} +
find . -name "*.pyc" -delete
```

Подождать синхронизации - Яндекс.Диск автоматически удалит из облака.

## Предотвращение проблемы в будущем

### 1. Создать .yandexignore

К сожалению, Яндекс.Диск CLI не поддерживает `.gitignore`-подобные файлы. Альтернативы:

**Вариант A:** Не синхронизировать папки с проектами, использовать Git для версионирования
**Вариант B:** Создать отдельную папку `pro_clean` без venv/cache и синхронизировать только её

### 2. Использовать .gitignore в каждом проекте

```gitignore
# Python
__pycache__/
*.pyc
*.pyo
*.pyd
.Python
venv/
.venv/
ENV/
env/

# Build
build/
dist/
*.egg-info/

# IDE
.vscode/
.idea/
.vs/

# Git
.git/
```

### 3. Pre-commit hook для проверки

Создать hook который не даст закоммитить venv:
```bash
#!/bin/bash
if git diff --cached --name-only | grep -q "venv/\|\.venv/"; then
    echo "❌ Попытка добавить venv в git!"
    exit 1
fi
```
