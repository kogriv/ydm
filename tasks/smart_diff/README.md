# Smart Diff: умное сравнение облака и локального состояния

**Статус: реализовано.** `report diff` сравнивает не просто "последний
cloud scan vs последний local scan", а строит композитный снимок:
данные из последнего *полного* облачного скана плюс обновления из более
свежих частичных сканов по отдельным папкам — иначе частичный скан одной
папки делал бы весь diff бессмысленным.

- **Как пользоваться:** [HOW_TO_USE.md](HOW_TO_USE.md) — команды,
  формат вывода, настройка, troubleshooting.
- **Проблема и решение:** [TASK_SMART_DIFF.md](TASK_SMART_DIFF.md)
- **Эвристика выбора "полного" скана** (и как она провалидирована на
  реальных данных): [FULL_SCAN_HEURISTICS.md](FULL_SCAN_HEURISTICS.md)

```bash
# Умное сравнение (композитный снимок автоматически)
python3 ydm.py report diff

# С указанием конкретных сканов
python3 ydm.py report diff --cloud-scan-id 42 --local-scan-id 10
```
