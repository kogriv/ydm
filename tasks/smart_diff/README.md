# Smart Diff: Умное сравнение облака и локального состояния

## Краткое описание

Реализация умного механизма сравнения облачного и локального состояния с поддержкой:
- Композитных снимков (полный скан + обновления из частичных)
- Явного указания scan_id для сравнения
- Автоматического определения актуального состояния

## Проблема

Текущая команда `report diff` использует последний cloud scan независимо от того, был ли он полным или частичным. Это приводит к неактуальным сравнениям, когда последний скан был только для одной папки.

## Решение

Построение композитного снимка:
1. Базовые данные из последнего полного скана
2. Обновления из последних частичных сканов по каждой папке
3. Объединение в итоговую виртуальную таблицу

## Быстрый старт

После реализации:
```bash
# Автоматическое умное сравнение
python3 ydm.py report diff

# С указанием конкретных сканов
python3 ydm.py report diff --cloud-scan-id 42 --local-scan-id 10
```
