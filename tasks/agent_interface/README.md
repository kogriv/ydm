# Интерфейс YDM для агентов

*Задача:* сделать так, чтобы CLI-агент без контекста прошлых сессий мог
выполнить типовую задачу синхронизации только штатными командами YDM и
надёжно понять, чем она закончилась.

## Статус

- Gap analysis: ✅ [`GAP.md`](./GAP.md)
- Backlog: ✅ [`BACKLOG.md`](./BACKLOG.md)
- Design: не требуется для Phase 1–2; для Phase 3–4 — по необходимости
- Implementation: не начата

## Границы

Здесь только машинный интерфейс: коды возврата, структурированный вывод,
инструкции для агентов, составные операции. Интерфейс для человека
(`ydm`, меню) — в [`tasks/ydm_menu/`](../ydm_menu/README.md), его разбор
идёт отдельно.

Правило для всех файлов задачи: репозиторий публичный, поэтому разбор
описывает поведение инструментов и не содержит имён личных файлов, адресов,
имён хостов и сведений об учётных записях.
