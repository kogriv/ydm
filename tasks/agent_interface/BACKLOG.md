# Интерфейс YDM для агентов — Backlog

*Дата:* 2026-10-31
*Разбор:* [`GAP.md`](./GAP.md)
*Scope:* агент выполняет типовые задачи штатными командами и надёжно видит
результат.

Порядок по value/risk: сперва то, что делает результат видимым, потом то, что
убирает обходные пути.

Для всех задач: репозиторий публичный — в тестах, документации и коммитах только
синтетические пути; поведение без ошибок не меняется побайтно, если это не цель
задачи; запуски только на временных каталогах, не на боевой конфигурации.
