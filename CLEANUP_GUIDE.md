# Руководство по очистке Яндекс.Диска от мусора

**Задача:** Удалить из облака тяжелые и ненужные папки (`node_modules`, `vcpkg`, `.git`, `venv`, `__pycache__`), которые попали туда из-за отсутствия исключений. Это ускоряет синхронизацию и освобождает место.

**Подход:** Используется безопасная двухэтапная схема (Plan -> Execute) с защитой от сбоев (Checkpointing).

---

## 1. Архитектура решения

Процесс разделен на два независимых скрипта:

### Этап 1: Планирование (`plan_cleanup.py`)
*   **Вход:** База данных `monitor.db` (результат сканирования `ydm.py`).
*   **Логика:** 
    1. Ищет в БД папки и файлы по критериям мусора (имена `venv`, `bin`, расширения `.tmp` и др.).
    2. Применяет **оптимизацию вложенности**: если удаляется папка `venv`, то удалять ее подпапки `__pycache__` отдельно не нужно — они удалятся вместе с родителем.
*   **Выход:** Файл `junk_list.txt` (список путей для удаления).

### Этап 2: Исполнение (`run_cleanup.py`)
*   **Вход:** Файл `junk_list.txt` и токен из `.env`.
*   **Логика:**
    1. Читает список задач.
    2. Читает журнал уже выполненного `deleted.log` (чтобы можно было прервать и продолжить).
    3. Отправляет API запросы `DELETE` в Яндекс.Диск.
    4. Обрабатывает ошибки (404 пропускает как успех, 429 ждет).
*   **Выход:** Обновляемый журнал `deleted.log` и чистое облако.

---

## 2. Критерии очистки (что удаляем)

Список формируется в `plan_cleanup.py`. На текущий момент удаляются:

**Папки (целиком с содержимым):**
*   `vcpkg` (Сборки C++ библиотек)
*   `node_modules` (JS библиотеки)
*   `.git` (История версий) — *предварительно убедитесь, что код запушен в origin!*
*   `venv`, `.venv` (Виртуальные окружения Python)
*   `__pycache__` (Байткод Python)
*   `bin`, `obj` (Компиляты C#/C++)

**Файлы:**
*   `*.tmp` (Временные файлы)
*   `*.log` (Логи)

**Исключения (Safe List):**
*   `.idea`, `.vscode` — эти папки **не удаляются**, настройки редакторов сохраняются.

## 3. Инструкция по запуску

### Шаг 0: Подготовка (Сканирование)
Перед планированием нужно иметь актуальный слепок облака в БД.
```bash
# Если база устарела
python3 ydm.py scan --cloud
```

### Шаг 1: Генерация плана
```bash
python3 plan_cleanup.py
```
*Результат:* Создастся файл `junk_list.txt`. Можно открыть его и проверить глазами.

### Шаг 2: Запуск очистки
```bash
python3 run_cleanup.py
```
*   Скрипт будет показывать прогресс-бар.
*   Можно безопасно прерывать (`Ctrl+C`) и запускать снова — он продолжит с места остановки.
